# MEDTRACK

A modern medication tracking and healthcare management application built with React, TypeScript, and Vite.

## 🚀 Features

- **Medication Management**: Track dosages, schedules, and adherence.
- **Safety & Verification**: Digital medication safety checks and health data monitoring.
- **Modern Web Stack**: Built with React 19, TypeScript, TailwindCSS, and Vite for fast performance and responsive design.

## 🛠️ Getting Started

### Prerequisites

- [Node.js](https://nodejs.org/) (v18 or higher)
- npm or yarn

### Installation

```bash
npm install
```

### Development

Run the local development server:

```bash
npm run dev
```

### Production Build

Create an optimized production build:

```bash
npm run build
```
